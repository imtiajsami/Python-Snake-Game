## About the Game

Snake Game is a simple 2D arcade game developed using Python Turtle Graphics. The player controls a snake to eat food, increase the score, and grow longer. The game ends when the snake hits the wall or its own body.

## How to Play

- **Arrow Up / W:** Move Up
- **Arrow Down / S:** Move Down
- **Arrow Left / A:** Move Left
- **Arrow Right / D:** Move Right
- **SPACE:** Start the Game
- **R:** Restart the Game
- **Close Window:** Quit the Game

## Features

- 2D Graphical Game Window
- Keyboard Controls
- Snake Movement
- Random Food Generation
- Snake Growth After Eating Food
- Score System
- High Score Tracking
- Wall Collision Detection
- Self-Collision Detection
- Game Over Screen
- Final Score Display
- Start Menu
- Restart Option
- Dark Background with Colorful Graphics
